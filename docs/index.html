Your languages, from the code Claude writes with you

langstats is a Claude Code plugin. It records the programming languages Claude reads and edits while it works for you, and turns them into a block of text bars for your GitHub profile README.

Install it Read the docs 

    
Choose it in Claude Code with /langstats:style bars

  

  
What it measures: the time Claude spends working in each language. It does not measure the time you spend typing in your own editor.


  

    
Why langstats

    

      

        
Only real code

        
Screenshots, PDFs and binaries are never recorded. Data, config and prose formats (Markdown, JSON, YAML…) are left out by default.

      

      

        
GitHub is optional

        
Connected, it updates your README by itself. Not connected, it gives you the block to paste by hand.

      

      

        
Does not slow Claude down

        
The hook is asynchronous, takes about 25 ms, and never touches the network or git.

      

      

        
Your own style

        
Bars, flowers 🌸, rockets 🚀, hearts 💖, moons 🌕 or any symbols you like.

      

      

        
Several computers

        
Turn on sharing and the stats of every computer add up instead of replacing each other.

      

      

        
Everywhere

        
macOS, Linux and Windows. Only Python 3.9 or newer is needed.

      

    

  


  

    
Get started

    
    
      
  1. 
        
    Install the plugin. In Claude Code:
    
        
    /plugin marketplace add codecruz/langstats
/plugin install langstats@codecruz
    
        
    Then start a new session, or run /reload-plugins.
    
      
    2. 
      
  2. 
        
    Run the guided setup. It detects whether GitHub is connected and asks a few questions.
    
        
    /langstats:setup
    
      
    3. 
      
  3. 
        
    Work as usual. Check your stats at any time:
    
        
    /langstats:stats
    
      
    4. 
      
  4. 
        
    Publish to your README, or let it publish by itself:
    
        
    /langstats:publish
    
      
    5. 
    

  


  

    
Privacy

    
    
      
  • Everything stays on your computer, in ~/.claude/langstats/.
    • 
      
  • Each record holds the time, the language and the project folder name. File paths and file contents are never stored.
    • 
      
  • When you publish, only the stats block goes to your repository: language names and percentages, no times.
    • 
      
  • In manual mode, or while GitHub is not connected, nothing is sent at all.
    •
